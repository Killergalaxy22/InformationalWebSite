Введение в веб-технологии

Современная веб-разработка базируется на «трех китах»: HTML (структура), CSS (оформление) и JavaScript (интерактивность). В этой статье мы разберем первые два компонента, которые являются фундаментом для любого фронтенд-разработчика.

HTML: Скелет вашей страницы

HTML (HyperText Markup Language) — это язык разметки, который сообщает браузеру, какие элементы должны быть на странице: заголовки, абзацы, изображения или ссылки.

Важно помнить: HTML описывает семантику (смысл) контента, а не его внешний вид.

Пример базовой структуры HTML-документа:

<!DOCTYPE html>
<html>
<head>
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый параграф.</p>
</body>
</html>

CSS: Магия стилей

CSS (Cascading Style Sheets) позволяет превратить черно-белый текст в современный интерфейс. С помощью CSS мы управляем цветами, шрифтами, отступами и расположением элементов.

Основные концепции CSS:

  • Селекторы: указывают, к какому элементу применить стиль.
  • Свойства: определяют, что именно мы меняем (color, margin, font-size).
  • Блочная модель: понимание того, как складываются content, padding, border и margin.

Пример стилизации заголовка:

h1 {
    color: #5c86ad;
    font-size: 24px;
    text-align: center;
    border-bottom: 2px solid #81c784;
}

Современные подходы: Flexbox и Grid

Раньше верстка сайтов была сложной задачей из-за использования таблиц или обтеканий (floats). Сегодня стандартом являются Flexbox (для одномерных макетов) и CSS Grid (для двумерных сеток). Они позволяют создавать адаптивные сайты, которые одинаково хорошо выглядят на смартфонах и мониторах.

Заключение

Изучение HTML и CSS — это первый и самый важный шаг в мир IT. Освоив эти технологии, вы сможете создавать интерфейсы любой сложности и переходить к изучению программирования на JavaScript.
